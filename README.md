# Shaji

Shaji is a React Native app for the Aqua track of Eth Safari Hackathon 2025. It uses the Aqua SDK.

## Prerequisites

- Node.js 20 or later and npm
- Android Studio with the Android SDK and an Android emulator or connected device
- For iOS builds, macOS with Xcode installed

Check your React Native environment with:

```sh
npx react-native doctor
```

## Get started

Clone the repository and install its dependencies:

```sh
git clone https://github.com/Wilberforcedev/Shaji-Authentication-Aqua.git
cd Shaji-Authentication-Aqua
npm ci
```

Start Metro in one terminal:

```sh
npm start
```

In a second terminal, build and launch the Android app:

```sh
npm run android
```

To run the iOS app on macOS, start Metro and run:

```sh
npm run ios
```
